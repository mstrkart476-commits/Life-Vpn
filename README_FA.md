# پروژه اندروید Life VPN

این پروژه یک نمونه اولیه اندروید است و رابط فارسی، افزودن دستی لینک‌های VLESS/VMess/Trojan، دریافت اشتراک متنی/Base64 و اسکن QR را دارد.

## ساخت APK
پروژه را با حفظ ساختار پوشه‌ها در یک مخزن GitHub قرار دهید. سپس از تب Actions گردش‌کار `Build Life VPN APK` را اجرا کنید و Artifact با نام `LifeVPN-debug-apk` را دریافت کنید.

## محدودیت مهم
این نسخه هنوز هسته Xray/V2Ray و Android VpnService ندارد؛ بنابراین دکمه اتصال تونل VPN واقعی برقرار نمی‌کند. برای انتشار یا استفاده واقعی، باید هسته سازگار و سرویس VPN، مدیریت مجوزها و تست امنیتی اضافه شود.
